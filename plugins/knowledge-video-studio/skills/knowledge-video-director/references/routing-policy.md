# Visual routing policy

Choose the visual that most directly explains the beat. Use `hybrid` only when two layers are genuinely necessary.

## `stock`

Use for observable reality: people performing an action, places, tools, nature, manufacturing, laboratories, daily behavior, architecture, and literal examples. Stock is strongest when the audience needs evidence that a thing exists or a process looks a certain way.

Do not use stock for invisible mechanisms, precise comparisons, unsupported historical reenactments, or abstract claims such as “trust is declining.” Search for the observable proxy instead, or use motion graphics.

## `hyperframes`

Use for relationships and systems: causal chains, networks, timelines, maps, taxonomies, feedback loops, layered concepts, equations, spatial explanation, and data stories whose form benefits from bespoke visual composition.

Prefer HyperFrames when the idea requires a custom visual grammar or several coordinated elements across a scene. Group adjacent HyperFrames beats into one coherent composition where possible.

## `remotion`

Use for parameterized and repeatable motion: charts driven by JSON, numeric counters, UI walkthroughs, code traces, tables, kinetic type, branded templates, and exact frame-based sequencing. Prefer it when the same scene family will be rendered with different data or aspect ratios.

Do not use Remotion merely because text needs to appear. If the visual is a one-off conceptual diagram, HyperFrames is usually a better fit.

## `editorial_collage`

Use sparingly for a strong opening, chapter turn, cultural/historical contrast, conflict, or editorial metaphor. Build original paper-cut compositions from licensed or generated elements. It should feel authored, not like a branded imitation of a news publisher.

Default cap: 30% of total duration. Never use a publisher's logo, lower-third, signature title treatment, or imply endorsement.

## `hybrid`

Use when literal footage needs an explanatory layer: labels over machinery, a map over a travel shot, quantified callouts over a physical scene, or a tracked highlight. Record the base media requirements and overlay renderer separately.

## Tie-breakers

1. Choose the mode that reduces ambiguity for the viewer.
2. Prefer existing licensed footage when literal reality is the point.
3. Prefer data-driven animation for precise values.
4. Prefer custom conceptual animation for nonliteral mechanisms.
5. Prefer visual continuity over showcasing more tools.
6. If two modes are equally good, stay with the chapter's dominant mode.

## Pacing

- Stock shot: usually 2–5 seconds; avoid repeated generic clips.
- Motion explanation: usually 4–10 seconds; give relationships time to resolve.
- Hook collage: usually 2–6 seconds.
- Avoid more than 10 hard mode switches per minute.
- Use cuts for semantic progression; reserve elaborate transitions for chapter changes.
